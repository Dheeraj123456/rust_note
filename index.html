Key Concepts

This glossary covers the most important Rust concepts you'll encounter.

Ownership

Every value in Rust has a single owner. When the owner goes out of scope, the value is dropped.

Borrowing

You can borrow a value immutably or mutably, but not both at the same time.

Lifetimes

Lifetimes ensure that references don't outlive the data they point to.
